A real terminal on every device you own.

Termino runs a real shell on your computer and connects over SSH to the machines you look after — with an SFTP browser, port forwarding, and private keys that never leave your device.

Apache-2.0 no account no telemetry

A real shell

PTY-backed local shells on macOS, Linux, Windows and Android. Full xterm emulation, so vim, htop and tmux behave the way they do anywhere else — truecolour, mouse reporting, the alternate screen, and a bundled font with the box-drawing and Powerline glyphs those programs assume.

Host keys taken seriously

The first time you connect, Termino shows the server's fingerprint and asks. If that key ever changes the connection is refused — not warned about, refused — because a changed key is indistinguishable from someone intercepting you.

One login per host

Authenticate once. The shell, the file browser and every port forward share the same connection, so opening files on a machine you already have a shell on costs no second password and no second key touch.

What's in it

Everything the job actually needs

SFTP, whole folders

Browse, upload and download entire directory trees. You are told the file count and total size before anything moves, and symbolic links are skipped and counted rather than followed.

Port forwarding

Local, remote and dynamic SOCKS forwards, with live status for each one and a single connection carrying all of them.

ZModem, in the session

rz and sz move files through the terminal connection itself — what still works when SFTP is disabled, when you are three hops deep, or when you are on a serial console.

A path bar that completes

Type a remote path and press Tab. It completes directory names against the server the way a shell does, and remembers where you have been this session.

.local names that resolve

Termino asks the network over multicast DNS when the system resolver has no answer, so pi@my-server.local works on Android too, not just on a Mac.

Links that tell the truth

URLs in output are tappable, and programs can declare real hyperlinks with OSC 8. A declared link asks first and shows where it actually goes, because the words and the destination need not match.

Built for a phone too

A key bar carrying the Esc, Tab, Ctrl and arrow keys a touch keyboard does not have, with modifiers you tap once to arm and twice to lock. Snippets for the commands nobody remembers.

Search and record

Regular-expression search through the scrollback, including matches that span a wrapped line, and session recording exported as plain text or asciicast.

Keys you cannot export

On macOS and Linux, authenticate through the system SSH agent — 1Password, Secretive, a hardware token, a key in the Secure Enclave. Termino never sees the key at all.

Opening an unsigned build

This build is not signed or notarised, so macOS refuses it on first open. Go to System Settings → Privacy & Security, find Termino under the warning, and click Open Anyway. Or, from a terminal:

xattr -d com.apple.quarantine /Applications/termino.app

Installing from outside a store

Android asks you to allow installs from wherever you downloaded it. This build is signed with a development key rather than a store key, so if Termino later ships on Google Play you will need to uninstall this one first.

The Android App Bundle, the Windows .msix, an unsigned iOS build and a self-hostable web bundle are all on the releases page. The web build has no local shell and reaches SSH servers through a relay you run yourself — see tools/relay.

Honestly

What works where

Some of this is decided by the platforms rather than by Termino. Where a feature cannot work, the app says so in place instead of offering a button that fails.

Platform Local shell SSH Status
macOS Yes Yes Sandbox off, so it can run your programs
Android Yes, sandboxed Yes Builds and runs
iOS / iPadOS No — the platform forbids it Yes Local shell gated off with an explanation
Linux Yes Yes CI only — see below
Windows Yes Yes CI only — see below
Web No Yes, through a relay Self-hosted; not a hosted service

“CI only” means the Linux and Windows builds compile and pass their tests on every change, but nobody has yet run them on a real machine and judged them by eye. That is the only thing it means, and it is worth knowing before you download one.

iOS cannot spawn other programs and a browser cannot open a raw TCP socket. Termino does not pretend otherwise: those features are switched off at runtime with an explanation rather than failing mysteriously.

The system SSH agent works on macOS and Linux. Not on Windows, whose agent speaks over a named pipe that Dart cannot open — so the option is absent there rather than present and broken.

The macOS and Windows builds are unsigned. Signing certificates cost money and cannot live in a public repository. Each download above explains how to get past the warning.

Security

What Termino does with your keys

  • Keys stay in the keystore Private keys and passwords live only in the platform keystore — never in the app's database, never in a log, never in a crash report.
  • A changed host key is a hard stop Not a warning with a “connect anyway” button. Replacing a trusted key is a separate, deliberate action.
  • Nothing phones home No analytics, no crash reporting, no account, no sync. Data goes to the servers you choose to connect to, and nowhere else.
  • The relay carries ciphertext On the web the SSH protocol still runs in your browser, so a relay never sees a key, a password, or a byte of your session.

Each of these is held in place by a named test — the table is in SECURITY.md, along with the threat model and what Termino explicitly does not protect against.
